# ESIS нэвтрүүлэлт, сургалт, засвар үйлчилгээний төлөвлөгөө

**Хувилбар:** 1.0

**Баталсан огноо:** [ ]

**Баталсан:** [Албан тушаал, нэр]

**Хамрах хүрээ:** NomadKids ашиглах гэрээт сургуулийн өмнөх боловсролын байгууллага

Энэ төлөвлөгөө А/261 ерөнхий шаардлага #26, #27 болон А/465 §3.18-ын
урьдчилсан хугацааг хэрэгжүүлэхэд зориулагдсан. Байгууллага бүрийн эхлэх
огноог `T` гэж тэмдэглэнэ.

| ------------------------------------ | ------------------------------------------------------- |

## 5. Засвар үйлчилгээ

| Давтамж     | Ажил                                                              |
| ----------- | ----------------------------------------------------------------- |
| Өдөр бүр    | Health, queue failure, sync lag, attendance mismatch шалгах       |
| 7 хоног бүр | Failed job triage, correction SLA, support issue review           |
| Сар бүр     | Dependency/security update, ESIS catalog diff, capacity trend     |
| Улирал бүр  | Access review, restore drill, incident tabletop, training refresh |
| Жил бүр     | DR, retention, гэрээ, API scope, privacy assessment шинэчлэх      |

Security update-ыг эрсдэлийн түвшнээр: critical 24 цагт үнэлж, 72 цагт
засвар/mitigation; high 7 хоног; бусдыг сарын release-д оруулна. ESIS contract
өөрчлөгдвөл schema validation унаж sync зогсоно; unknown payload-ыг local
өгөгдөлд автоматаар бичихгүй.

## 6. Rollback ба incident

1. ESIS POST feature flag-ийг унтрааж read-only горимд шилжинэ.
2. Queue-г pause хийж, pending job-уудыг устгахгүй.
3. Token алдагдсан сэжигтэй бол secret-ийг revoke/rotate хүсэлт гаргана.
4. Local бүртгэлийг source of record хэвээр ажиллуулна.
5. Илгээсэн batch, response status, actor, timestamp-ийг audit-аас гаргана.
6. Залруулгыг А/465 §5.1.3-5.1.4-ийн ажлын 3 өдрийн урсгалаар шийднэ.

Go-live актанд байгууллага, scope API ID, эхлэх огноо, хариуцагчид, test run ID,
rollback шийдвэр гаргах хүнийг заавал бичнэ.
